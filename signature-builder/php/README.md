# PHP Signature Builder
- Install / configure PHP 8.1 or newer https://www.php.net/manual/en/install.php  (the configuration process may differ for different operation systems)
- install composer package manager https://getcomposer.org/download/
- run *composer install* in terminal in *signature-builder/php* folder
- run *php main.php* in terminal in *signature-builder/php* folder
- check the logs / created target on *https://dmarket.com/*
